# One Great Idea website

A responsive, buildless static website for One Great Idea Limited.

## Files

- `index.html` — page structure, content and SEO metadata
- `styles.css` — responsive layout, colours, typography and focus states
- `script.js` — mobile navigation, current footer year and enquiry form behaviour

## Preview

Open `index.html` in a browser, or serve this directory with any basic static web server. There is no build step or package installation.

## Enquiry form

The form validates the required name and email fields, then opens a pre-filled email draft to `together@onegreatidea.co.uk`. It does not send the enquiry automatically. For direct website submissions, connect a form service or backend before launch.

## Before connecting the domain

Confirm the package scope and contact details with One Great Idea Limited. The live site should continue to be the source of truth until this version has been reviewed and a hosting/deployment method is selected.
